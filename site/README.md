# Harness Firmware homepage

A standalone homepage built with HTML, CSS, JavaScript, and SVG artwork. No package installation or build step is needed; the preview server requires Node.js.

Run from the repository root:

```sh
node site/server.mjs
```

Open [the local preview](http://127.0.0.1:4348). The server binds to localhost and serves only the `site/` directory; paths that start with a dot (`.env`, `.local/`) are not served. Set `PORT` to use another port. This site has not been published.

The five-stage loop supports manual selection and a deterministic example replay, including a failed check, repair, and retained lesson. Replay is illustrative and does not execute repository actions. Reduced motion shows the complete example immediately. With JavaScript disabled, the default stage and the source disclosure explain the full process.

Third-party assets and their licenses are listed in [PROVENANCE.md](PROVENANCE.md). External links point to the project's source, web creator, and the CoreWise Academy process page.

## Fonts

Four open-licensed faces ship in `assets/fonts/`, each folder with its license. `fonts.css` declares them and sets one token per role; every page links it first and preloads the faces its first screen uses.

- `--font-display`: Lineal at weight 781, for huge type: the hero headline, statements and headings.
- `--font-accent`: Fraunces italic (weight 600, optical size 144, soft 100, wonky on), for the accent words: the hero's rotating word, the pillar words and the answering statement lines.
- `--font-text`: Mona Sans at weight 500, for sub-lines, body text, navigation and buttons. Mona Sans has a Reserved Font Name, so the subset shipped here is renamed Harness Text.
- `--font-mono`: Departure Mono, for typed commands, tags and labels, including the convergence canvas labels.

Huge type is tracked at -0.015em (`--display-track`). Lineal ships as released. The other files are subsets: Latin plus the punctuation and arrows the pages use, with every variable axis the site sets kept. Sources, versions and licenses are in [PROVENANCE.md](PROVENANCE.md).

## Motion hooks

`smooth-scroll.mjs` is the spring smooth-scroll engine, written for this site with no dependencies. Native scrolling moves the document; a fixed content layer trails it through a spring (stiffness 55, damping 15, mass 0.27) and a spacer keeps the document length. With `prefers-reduced-motion: reduce`, every page scrolls natively.

`statement-block.mjs` builds the pinned statements (`.statement-block`: the problem statement and the /long-horizon statement) from three reusable modules, each with its own stylesheet:

- `split-reveal.mjs`: splits a heading into masked lines, words and characters and plays the reveal once.
- `hover-grid.mjs`: a brick-offset grid of square cells with a green light that follows the pointer under the gaps; light and dark variants.
- `pixel-wipe.mjs`: a cols x rows grid of cells that fill in a shuffled (optionally seeded) order as a progress value runs from 0 to 1.

Each statement pins for its panel height plus 150svh of scroll, and its pixel wipe takes the color in `data-wipe` (the section underneath). Pinning, the reveal trigger and the wipe follow the smooth-scroll layer's rendered offset; without the engine the panel pins with `position: sticky` on native scroll. Reduced motion visitors get the static light panel with the whole statement; without scripting the panel is dark, so the transparent header stays legible over it.

`card-row.mjs` builds the command card rows (`.card-row`: Planned and Production-ready) from the same modules. The content box pins for the section plus 150svh of scroll while the next section slides over it; the pillar headline and the three cards reveal once, a dark hover grid and a pointer-following arc on each card frame answer the pointer, and a pixel wipe in the next section's color closes the pin. `card-art.mjs` draws a line animation of each command in the card media. Reduced motion visitors get the static cards with each drawing as a still frame.

## Project creator (/new)

`/new` is the hosted project creator. The page, styles, script, and skill catalog live in `new/`; the server side is `github-creator.mjs`, mounted by `server.mjs` under `/api/harness/github/*` (`status`, `connect`, `callback`, `select`, `disconnect`, `create`).

Without credentials the creator links to the GitHub template page. With a GitHub App configured, a person authorizes once, picks the skills to include, and the server generates the repository from `ryanportfolio/Harness-Firmware`, then commits `.claude/settings.json` overrides and removes the deselected skill directories. Tokens stay in encrypted HttpOnly cookies scoped to `/api/harness/github`; the browser never receives one.

Copy `.env.example` to `.env`, fill it from a GitHub App whose callback and setup URL point at `http://127.0.0.1:4348/api/harness/github/callback` (repository permissions: Administration and Contents, read and write), then start with:

```sh
node --env-file=site/.env site/server.mjs
```

Unit tests: `node --test site/github-creator.test.mjs`.
