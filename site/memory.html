MEMORY RULES

What earns a place

Worth saving +

Save with permission when all three apply:

  • Changes future decisions; costly to rediscover.
  • A lasting constraint, decision, or recurring pitfall.
  • Evidence supports it; uncertainty stays clear.
Keep it focused +

Keep task updates and one-off errors in working notes. Keep local details out of root instructions and secret values out of memory. Saving grants no permission to commit, push, or share across repos.

Review what gets used +

The audit counts recorded reads, writes, and skill use in local Claude transcripts. Coverage is partial; Codex is excluded. Review unread notes before removing them.

Keep it current +

Check notes against current code and behavior. Update stale entries, retain exceptions, and refresh dated evidence.
